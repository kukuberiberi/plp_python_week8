# Python Utility Toolkit (`plp-python-week8`)

## Project Overview
The **Python Utility Toolkit** is a clean, modular command-line application built in Python. It aggregates three practical everyday utilities under a unified, continuous menu interface, satisfying all core requirements for loops, mutable lists, and conditional logic.

---

## Included Tools
1. **Simple Calculator**: Executes basic arithmetic operations (+, `-`, `*`, `/`) with safety checks against division-by-zero crashes.
2. **To-Do List Manager**: Provides dynamic task tracking where items can be added and removed in real time during runtime.
3. **Number Guessing Game**: An interactive integer-guessing challenge powered by the Python `random` module.

---

## How to Run the Program
1. Ensure Python 3.x is installed on your machine.
2. Clone or download this repository.
3. Open your terminal or command prompt in the project directory and run:
   ```bash
   python toolkit.py
